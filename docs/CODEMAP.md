# Code map

Generated by `node scripts/codemap.mjs` — do not edit by hand. First doc-comment sentence per source file.

## crates/jpdict/src/

- crates/jpdict/src/build.rs — Build the SQLite dictionary from the JMdict JSON (jmdict-simplified format) and Kanjium's `accents.txt`.
- crates/jpdict/src/deinflect.rs — Deinflection: reduce a conjugated Japanese form to its dictionary form(s).
- crates/jpdict/src/dict.rs — Opening the database and looking words up at a position in a line.
- crates/jpdict/src/error.rs — Everything that can go wrong while building or opening the dictionary.
- crates/jpdict/src/furigana.rs — Furigana: align the kanji runs of a written form with its kana reading.
- crates/jpdict/src/kana.rs — Small kana/kanji helpers (kept local so this crate stands alone).
- crates/jpdict/src/lib.rs — Japanese-English dictionary: building the SQLite database (JMdict + Kanjium), deinflection, lookup at a position, pitch accent and furigana.
- crates/jpdict/src/pitch.rs — Pitch accent: mora splitting and accent pattern from a Kanjium downstep number.
- crates/jpdict/src/store.rs — The compact per-entry record stored as JSON in the `entries` table (short keys keep the database small).
- crates/jpdict/src/types.rs — The JSON the front end receives.

## scripts/

- scripts/ci.mjs — Local CI: runs every gate in order, stops at the first failure, ends with `CI OK` or `CI FAILED: <step>`.
- scripts/codemap.mjs — Writes docs/CODEMAP.md: every source file with its first doc-comment sentence (--check fails if the file is stale).
- scripts/fetch-deps.mjs — Downloads the pinned third-party binaries (libmpv, libmpv-wrapper, ffmpeg/ffprobe), checks their SHA-256 and installs them into src-tauri/lib/.
- scripts/make-samples.mjs — Generates small synthetic test videos in samples/ (Hi10P H.264 MKV + ASS/SRT, HEVC 10-bit MKV, H.264 MP4) for the player spike and tests.
- scripts/ship.mjs — One-command ship (AGENT-WORKFLOW section 6): merge main, bump, memory check, CI, commit, push, PR, gate, merge, release; ends with `SHIP OK`.

## scripts/dev/

- scripts/dev/cdp.mjs — Evaluates a JS expression in the running app's WebView2 over the remote-debugging port (CDP_PORT, default 9222); dev tool.
- scripts/dev/fake-anki.mjs — Fake AnkiConnect on 127.0.0.1:8765 for trying the mining flow without Anki; logs requests to artifacts/probe/fake-anki.jsonl.

## scripts/guards/

- scripts/guards/encoding.mjs — Guard: every text file is valid UTF-8 with LF endings, no BOM and no stray control characters.
- scripts/guards/licenses.mjs — Guard: every Rust and production JS dependency has a licence on the allow-list (docs/DESIGN.md section 8).
- scripts/guards/mpv.mjs — Guard: UI code never asks the libmpv plugin for the 'node' format (it segfaults the app; read node properties as 'string' JSON).
- scripts/guards/network.mjs — Guard: source code may only talk to loopback (AnkiConnect, mpv) and the DeepL module; no other URLs or HTTP clients.
- scripts/guards/stores.mjs — Guard: persistent stores go through src-tauri/src/stores.rs only (no other Rust code names a .json file or uses localStorage for data).

- src-tauri/src/commands.rs — Tauri commands behind src/lib/backend.ts: prepare a file, cues, alignment, tokenizing, dictionary lookup, word audio, per-file state, recents.
- src-tauri/src/lib.rs — Kotoba Player: Tauri entry point (plugins, the Rust core's state, commands).
- src-tauri/src/library.rs — Per-file memory: resume position, subtitle offset, chosen subtitle tracks, and the "Continue watching" list.
- src-tauri/src/main.rs — (no doc comment)
- src-tauri/src/media.rs — Media probing and subtitle extraction with the bundled ffprobe/ffmpeg (tracks, external subtitle files, cache paths).
- src-tauri/src/mining.rs — Anki card fields from a clicked word: furigana in Anki syntax, the bolded sentence, meanings, the pitch SVG (pure, tested).
- src-tauri/src/settings.rs — App settings stored through the stores registry (`settings.json`): Anki, translation, subtitles and appearance.
- src-tauri/src/stores.rs — The registry of every file the app stores (one place, explicit backup decision), with atomic JSON reads/writes.
- src-tauri/src/sync.rs — Automatic subtitle sync: retime a subtitle track against a reference track with alass (handles ad breaks / splits).
- src-tauri/src/translate.rs — Sentence translation chain for cards without an English subtitle line: DeepL (owner's key) → local Ollama → none.
- src-tauri/src/translate_deepl.rs — Sentence translation with DeepL (the owner's own API key from the OS keyring; Free keys use api-free.deepl.com).
- src-tauri/src/translate_ollama.rs — Sentence translation with a local Ollama model (127.0.0.1:11434 only; free and offline).
