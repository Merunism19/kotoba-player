# Code map

Generated by `node scripts/codemap.mjs` — do not edit by hand. First doc-comment sentence per source file.

## crates/jptext/src/

- crates/jptext/src/lib.rs — Japanese text tools: tokenizing a subtitle line into word units (whole words, readings, base forms) and kana utilities.

## crates/subtitles/src/

- crates/subtitles/src/lib.rs — Subtitle parsing (ASS/SSA, SRT, WebVTT) into cues, sign/song classification, and JP↔EN alignment.

## scripts/

- scripts/ci.mjs — Local CI: runs every gate in order, stops at the first failure, ends with `CI OK` or `CI FAILED: <step>`.
- scripts/codemap.mjs — Writes docs/CODEMAP.md: every source file with its first doc-comment sentence (--check fails if the file is stale).
- scripts/fetch-deps.mjs — Downloads the pinned third-party binaries (libmpv, libmpv-wrapper, ffmpeg/ffprobe), checks their SHA-256 and installs them into src-tauri/lib/.
- scripts/make-samples.mjs — Generates small synthetic test videos in samples/ (Hi10P H.264 MKV + ASS/SRT, HEVC 10-bit MKV, H.264 MP4) for the player spike and tests.
- scripts/ship.mjs — One-command ship (AGENT-WORKFLOW section 6): merge main, bump, memory check, CI, commit, push, PR, gate, merge, release; ends with `SHIP OK`.

## scripts/dev/

- scripts/dev/cdp.mjs — Evaluates a JS expression in the running app's WebView2 over the remote-debugging port (CDP_PORT, default 9222); dev tool.

## scripts/guards/

- scripts/guards/encoding.mjs — Guard: every text file is valid UTF-8 with LF endings, no BOM and no stray control characters.
- scripts/guards/licenses.mjs — Guard: every Rust and production JS dependency has a licence on the allow-list (docs/DESIGN.md section 8).
- scripts/guards/mpv.mjs — Guard: UI code never asks the libmpv plugin for the 'node' format (it segfaults the app; read node properties as 'string' JSON).
- scripts/guards/network.mjs — Guard: source code may only talk to loopback (AnkiConnect, mpv) and the DeepL module; no other URLs or HTTP clients.
- scripts/guards/stores.mjs — Guard: persistent stores go through src-tauri/src/stores.rs only (no other Rust code names a .json file or uses localStorage for data).

## scripts/lib/

- scripts/lib/util.mjs — Shared helpers for repo scripts: repo root, process running, file listing.

## src/

- src/main.tsx — Entry point: loads bundled fonts and tokens, installs the mock backend/player in `?mock=1` mode, then renders the app.
- src/vite-env.d.ts — <reference types="vite/client" />

## src-tauri/src/

- src-tauri/src/commands.rs — Tauri commands behind src/lib/backend.ts: prepare a file, cues, alignment, tokenizing, per-file state, recents.
- src-tauri/src/lib.rs — Kotoba Player: Tauri entry point (plugins, the Rust core's state, commands).
- src-tauri/src/library.rs — Per-file memory: resume position, subtitle offset, chosen subtitle tracks, and the "Continue watching" list.
- src-tauri/src/main.rs — (no doc comment)
- src-tauri/src/media.rs — Media probing and subtitle extraction with the bundled ffprobe/ffmpeg (tracks, external subtitle files, cache paths).
- src-tauri/src/stores.rs — The registry of every file the app stores (one place, explicit backup decision), with atomic JSON reads/writes.

## src/app/

- src/app/App.tsx — App shell: boots the session once, routes home <-> player, hosts toasts, and draws the mock video frame in screenshot mode.
- src/app/app.css — Global base styles: transparent page (mpv draws the video underneath), reset, toasts, drop veil.
- src/app/store.ts — Global UI state (zustand): current screen, prepared media, cues, playback props, popup, toasts.

## src/design/

- src/design/tokens.css — Design tokens for the whole UI (docs/DESIGN.md section 5): colours, type, radii, shadows, motion; components use only these.

## src/features/home/

- src/features/home/Home.tsx — Home screen: full-window opaque page with logo, drop zone, "Open video" and the Continue watching row.

## src/features/player/

- src/features/player/Controls.tsx — Bottom control bar: seek bar, play/pause, line navigation, time, speed menu, volume, fullscreen.
- src/features/player/OffsetBadge.tsx — Subtitle offset badge ("+0.30 s"), shown when the offset is not zero and flashing on every change.
- src/features/player/PlayerScreen.tsx — Player screen: transparent stage over mpv's video with auto-hiding top/bottom bars, subtitle layer, popup and hotkeys.
- src/features/player/SeekBar.tsx — Seek bar: played fill, a tick per dialogue cue, knob, drag-to-seek and a hover time tooltip.
- src/features/player/SubtitleLayer.tsx — Subtitle layer: current Japanese dialogue line as hoverable/clickable word units, plus the aligned English line.
- src/features/player/Toasts.tsx — Toast stack (bottom-right glass cards, auto-dismissed by session.toast).
- src/features/player/TrackPicker.tsx — Track picker: chips in the top bar open a panel to choose the audio track and the Japanese / English subtitle tracks (any sub for either role).
- src/features/player/WordPopup.tsx — Placeholder dictionary popup (Phase 1): the clicked unit with its reading as ruby, anchored above the word with an arrow.
- src/features/player/icons.tsx — Inline SVG icons (stroke style, 24px grid) used across the player controls.
- src/features/player/player.css — Player screen styles: tinted (non-blurred) glass bars over the video, subtitle words, popup, seek bar, menus.
- src/features/player/session.ts — Playback session logic: opening files, position saving, line navigation, offset, track choices, toasts; glue between store, backend and mpv.

## src/lib/

- src/lib/backend.ts — The contract between the React UI and the Rust core (Tauri commands).
- src/lib/cues.ts — Binary searches over a start-sorted cue list: active cue at a time, previous and next cue.
- src/lib/env.ts — Runtime flags: `?mock=1` swaps in fake backend/player so the UI can be screenshotted without the desktop app.
- src/lib/format.ts — Small formatting helpers: clock times, "time left", subtitle offsets, file names, language labels.
- src/lib/hotkeys.ts — Player hotkeys (docs/DESIGN.md section 7): one keydown listener mapping keys to actions.
- src/lib/mock-backend.ts — Fake backend for screenshots: deterministic "Sunset Journey - 07" with the 7 sample lines, English, hand-made word units and 3 recents.
- src/lib/mock-player.ts — Fake player for screenshots: a 30 s clock that advances while unpaused and answers the same API as mpv.
- src/lib/mock-scene.css — Placeholder frame behind the transparent page in mock mode; `.bright` makes a near-white frame to test text contrast.
- src/lib/platform.ts — Desktop-shell helpers (file dialog, drag-and-drop, fullscreen) with harmless fallbacks in the browser/mock.
- src/lib/player.ts — The only module that talks to mpv (tauri-plugin-libmpv-api): init once, observe properties, load/seek/pause/volume/speed/audio; swappable for the mock in scree…
- src/lib/words.ts — Cached, de-duplicated tokenization of subtitle lines into word units, plus helpers to split a line into render segments.
